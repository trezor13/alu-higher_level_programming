# JavaScript Warm Up

This project contains solutions for the JavaScript Warm Up tasks. The exercises focus on learning the fundamentals of JavaScript using Node.js, including variables, functions, loops, arrays, objects, recursion, command-line arguments, and modules.

## Learning Objectives

- Run JavaScript scripts with Node.js
- Work with variables and data types
- Use functions and recursion
- Handle command-line arguments
- Use loops and arrays
- Manipulate objects
- Export and import modules

## Requirements

- Ubuntu 20.04 LTS
- Node.js
- Semistandard coding style
