# JavaScript Web Scraping

This project contains JavaScript scripts that work with files, web requests, and APIs using Node.js.

## Learning Objectives

By completing this project, I learned how to:

- Manipulate files using the Node.js `fs` module.
- Read files using UTF-8 encoding.
- Write content to files.
- Make HTTP requests using the `request` module.
- Work with command-line arguments using `process.argv`.
- Retrieve data from REST APIs.
- Parse JSON responses using `JSON.parse()`.
- Process and filter API data.
- Count and organize data using JavaScript objects.
